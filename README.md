# Travel Planner

Офлайн-first PWA для планування окремих подорожей. Дані кожної подорожі зберігаються лише на пристрої.

## Можливості

- маршрути, квитки, бюджет, щоденник, нотатки та чек-лист;
- JSON-експорт та імпорт;
- вкладення зберігаються локально в IndexedDB.

## Запуск

Відкрийте `index.html` через статичний вебсервер або GitHub Pages, а потім встановіть PWA на телефон через браузер.
